# Selenium Certification - ToolsQA

Repositorio de práctica y avances del curso de certificación en Selenium 
dictado por ToolsQA, como parte de mi formación en Ingeniería en Informática.

## Objetivo
Documentar el proceso de aprendizaje en automatización de pruebas con 
Selenium WebDriver, aplicando los ejercicios sobre demoqa.com.

## Tecnologías
- Selenium WebDriver (selenium-python)
- Python
- pytest
- Sitio de práctica: demoqa.com
